# Phase 7 — Public Exposure Recon

## Objective

Identify publicly exposed information related to the authorized target
through public repositories, code-hosting platforms, documents, metadata,
and public web intelligence sources.

The goal is to discover additional intelligence that may expand or
clarify the attack-surface map.

This phase is reconnaissance only.

---

## Scope

This phase focuses on:

- GitHub reconnaissance
- Public source-code discovery
- Secret discovery
- Public documents
- Document metadata
- Historical/public web intelligence
- Public infrastructure references
- Correlation with previously discovered assets
