# Phase 4 — Web Discovery

## Objective

Discover URLs, endpoints, parameters, links, JavaScript resources,
historical URLs, and accessible content associated with the live web
assets identified in previous phases.

The goal is to expand the known web attack surface before manual
security testing.

---

## Scope

This phase focuses on:

- Web crawling
- URL discovery
- Endpoint discovery
- Parameter discovery
- Historical URL discovery
- Content discovery
- Directory and file discovery
- Interesting web paths

JavaScript-specific analysis is handled in Phase 5.
