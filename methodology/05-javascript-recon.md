# Phase 5 — JavaScript Recon

## Objective

Collect and analyze JavaScript resources discovered during web
reconnaissance to identify URLs, endpoints, interesting strings,
configuration data, and potential secrets.

The goal is to extract additional application intelligence that may not
be visible through normal crawling.

---

## Scope

This phase focuses on:

- JavaScript collection
- JavaScript URL discovery
- Endpoint extraction
- URL extraction
- Interesting strings
- API references
- Configuration references
- Potential secrets
- Correlation with previously discovered endpoints
