# Phase 3 — Technology & Infrastructure

## Objective

Identify the technologies, open ports, exposed services, and basic
infrastructure characteristics associated with the live assets discovered
in Phase 2.

The goal is to understand the technical surface of the target before
moving into deeper web discovery.

---

## Scope

This phase focuses on:

- Technology fingerprinting
- Web server identification
- Port discovery
- Service identification
- Service version detection
- Infrastructure relationships
- Interesting exposed services

Web crawling, historical URL discovery, and content discovery are
handled in Phase 4.
